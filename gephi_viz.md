# Визуализация графа в Gephi

Рецепты для графа `gephi_output_v2/history_of_medicine.gexf`
(импорт: `File → Open`, выбрать `.gexf`; альтернативно `File → Import Spreadsheet` для CSV).

## 1. Анимация во времени

GEXF уже динамический (`mode="dynamic"`, у каждого узла есть `start`/`end`).

- После импорта включите **Timeline** (иконка «часы» внизу окна Overview).
- Ползунок фильтрует узлы по интервалу дат; кнопкой Play можно проиграть историю.
- Отрицательные годы — это до н.э. (например, `-3100`). Если ползунок с отрицательными
  значениями неудобен, в Data Laboratory создайте колонку «Год = Start + 5000» и
  используйте её как время.

## 2. Окраска по типу и раскладка

- Цвет уже задан в GEXF через `viz:color`:
  - `era` — серый, `concept` — зелёный, `practice` — бирюзовый,
  - `discovery` — оранжевый, `institution` — фиолетовый, `person` — синий,
  - `text` — коричневый, `team` — индиго, `context` — розовый,
  - `ethic` — красный, `disease` — тёмно-красный.
- Если нужно перекрасить вручную: панель **Appearance → Nodes → Partition → Kind**.
- Размер: **Appearance → Nodes → Rank → Size** (или атрибут `Degree`).
- Раскладка: **Layout → ForceAtlas2**:
  - `Scaling = 10–20`, включить `Prevent Overlap` и `Approximate Repulsion`;
  - `LinLog` — для разреженных ветвей; `Gravity = 1–5`, чтобы не расползалось.

## 3. Тематические срезы (фильтры по Relation)

Фильтры: **Filters → Edges → Relation** (через `AND`/`OR` объединять нужные):

- **Эпидемии**: `VACCINE_FOR` + `TREATS` + `DISCOVERED` + `EPIDEMIC_IN` →
  сеть «болезнь → возбудитель/вакцина/лекарство/эпоха».
- **Научная генеалогия**: `MENTORED` + `INFLUENCED` → дерево учителей и учеников.
- **Институты и тексты**: `HOSTS` + `AUTHORED` + `DEFINES` → кто где работал и что написал.
- Фильтр по типу узла: **Filters → Nodes → Kind** (например, только `disease`).

После фильтрации жмите **Filter** (включить) и при необходимости заново запустите ForceAtlas2.

## 4. Хабы по степени

- `Degree` уже посчитан скриптом и экспортирован как атрибут узла.
  **Appearance → Nodes → Rank → Degree** — увеличить/перекрасить топ.
  Лидеры: Гален, Гиппократ, Кох, Пастер, Авиценна.
- Альтернативно Gephi пересчитает сам: **Statistics → Average Degree**.
