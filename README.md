# MedHistory — концепт-карта истории медицины

Автор: Самаркин А.И.

Интерактивный концептуальный граф истории медицины: эпохи, концепции, персоны,
тексты, открытия, болезни и этика — с акцентом на врачей и учёных России и СССР.

## Что это

- **`graphV4.html`** — основная самодостаточная визуализация (без внешних
  зависимостей): смена раскладки (силовая / расталкивание / ForceAtlas2 / дерево /
  круг), светлая/тёмная тема, умный поиск узлов (частичный ввод и допуск опечаток),
  карточки узлов и связей со ссылками на поиск.
- `graphV3.html`, `graph.html`, `graph_timeline.html` — другие варианты.

## Деплой / раздача пользователям

`graphV4.html` — **один файл, всё встроено** (vis.js, данные, стили). Никаких
внешних CDN и сервера не нужно:

1. **Просто открыть** — двойной клик по файлу в любом браузере
   (Chrome / Firefox / Safari / Edge) на Windows, macOS или Linux.
2. **Статический хостинг** — загрузить `graphV4.html` на GitHub Pages, Netlify,
   Vercel или любой веб-сервер и раздать ссылку.
3. **Лаунчер** — `python launch.py` откроет граф в браузере по умолчанию.

Интернет для работы не требуется.

## Кроссплатформенное «приложение»

Сам `graphV4.html` и есть кроссплатформенное приложение — работает везде, где есть
браузер. Если нужен нативный исполняемый файл (без Python и без браузера вручную):

```bash
pip install pyinstaller
pyinstaller --onefile launch.py
# распространять dist/launch (или launch.exe на Windows) вместе с graphV4.html
```

## Пересборка (для разработчика)

```bash
uv sync                       # зависимости: networkx, pyvis, plotly, numpy

# 1) данные — править graph_extra.json (расширенная база) или BaseGraphGen.py
# 2) пересобрать CSV/GEXF для Gephi:
uv run python BaseGraphGen.py
# 3) пересобрать HTML-визуализацию:
uv run python viz_pyvis_v4.py    # -> graphV4.html (самодостаточный)
```

## Структура

- `BaseGraphGen.py` — генератор графа (валидация связей, экспорт CSV/GEXF).
- `graph_extra.json` — расширенная база знаний (данные отдельно от кода).
- `viz_pyvis.py`, `viz_pyvis_v2.py`, `viz_pyvis_v3.py`, `viz_pyvis_v4.py`,
  `viz_plotly.py` — генераторы HTML-визуализаций.
- `launch.py` — кроссплатформенный лаунчер.
- `gephi_output_v2/` — экспорт для Gephi (nodes/edges.csv, .gexf, report.txt).
